Cost Analysis Interactive Labs

Five browser-based tools for training, intuition-building, and communicating assumptions: the AI Bias Sandbox, Galton Board Distribution Lab, K-Means Clustering Lab, CASE (Cost Analysis & Simulation Engine), and the Regression Analysis Tool (RAT). No install required—just open and use.

Explore how AI + analytics workflow choices can increase bias exposure and governance risk. Adjust assumptions and see outputs update instantly.

Monte Carlo S-curve / CDF Tour + Tooltips

Galton Board Distribution Lab

Build distribution intuition using a Galton-board lab that connects sampling to cost-risk outputs (PDF and CDF “S-curve”).

  • Sampling modes (e.g., Monte Carlo / Latin Hypercube)
  • Distribution options and u→Q(u) quantile mapping
  • Cost PDF + Cost CDF (S-curve) views with percentiles

Unsupervised ML K-means++ Elbow / Silhouette v0.7.5.2

K-Means Clustering Lab

An interactive K-means “sandbox” for building intuition: click to add points, step through iterations, and use diagnostics to pick k.

  • Teaching vs Analysis mode, k-means++ or random initialization, step/auto-run
  • K-scan helpers (elbow and silhouette) plus diagnostics and exports
  • CSV upload + presets + normalization for quick experiments

Cost Estimating WBS-driven Risk / Monte Carlo v3.0.17

CASE — Cost Analysis & Simulation Engine

A browser-based estimating workflow: build a WBS, enter cost lines, apply uncertainty, and generate cost-risk outputs (including PDF/CDF “S-curve” views).

  • WBS templates + library to jump-start structuring (MIL-STD style layouts)
  • Risk distributions, sampling, and summary statistics for “what-if” exploration
  • Exports and sharing-friendly outputs for documentation and briefings

Regression Run-all leaderboard OLS + MUPE/ZMPE v1.0.0

Regression Analysis Tool (RAT)

Upload or paste data, then run a full model search to get a ranked leaderboard of regression candidates (with metrics, coefficient stats, and interval bands where applicable).

  • One-click Run all fits across common model families (linear / log / polynomial)
  • Rank by RMSE / R² / Adj R² / AIC / BIC, with optional p-value filtering
  • Optional advanced percent-error minimizers (MUPE / ZMPE) and multi-X subset search

What these are

These tools are designed for education, demos, and communicating assumptions in cost-analysis contexts. They are not validated pricing engines or compliance audit instruments.
