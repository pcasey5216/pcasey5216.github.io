Overview

          

            RAT fits many regression forms to paired data (x,y) and ranks them with defensible metrics.
            Some models are fitted in a fit space (e.g., log(y)), then predictions are back-transformed to the original y-units for plotting and apples-to-apples comparison.
          

          
    
            
  • Current Fit shows one selected model (equation, coefficients, predictions, CI/PI).
    • 
            
  • Model Search enumerates model candidates, evaluates them, and populates the Leaderboard.
    • 
            
  • Compare lets you overlay multiple top models and export the selected set.
    • 
          

        


        

          
Metrics glossary

          

            
MetricMeaning (high level)

            
              
RMSERoot-mean-square error in original y-units (lower is better). Weighted form uses Σw·(y−ŷ)² / Σw.

              
R²Fraction of variance explained (higher is better). Computed in the same space as the displayed residuals.

              
Adj R²R² adjusted for number of predictors/terms (penalizes overfitting).

              
AIC / BICInformation criteria (lower is better). Useful when comparing models with different complexity.

              
t / pCoefficient significance tests (OLS/WLS exact in fit space; MUPE/ZMPE are approx/experimental).

              
MPE%Mean percent error: 100·mean_w((y−ŷ)/y). Positive means under-predict on average.

              
MAPE%Mean absolute percent error: 100·mean_w(|(y−ŷ)/y|).

              
RMSE%Percent RMSE: 100·sqrt(mean_w(((y−ŷ)/y)²)).

            
          

          
Tip: use RMSE for units-based accuracy and AIC/BIC when comparing different model complexities.

FamilyFit-space formBack-transform

If No-intercept is enabled, the “a” term is removed (model forced through the origin).

        


        

          
Multi-X & feature subset search

          

            Multi-X lets you fit a Multiple Linear Regression (MLR) using several predictors at once.
            In RAT, Multi-X is used in two places:
          

          
    
            
  • Current Fit: enable “multi-X” to compute an MLR fit immediately for your selected predictors.
    • 
            
  • Model Search: enable Feature subset search to build a bounded leaderboard of candidate predictor sets.
    • 
          


          
Subset search (bounded best-subset)

          

            Subset search evaluates many predictor combinations (up to “Max predictors”) and ranks them (often by AIC).
            “Candidate cap” limits how many predictors are considered (after correlation screening) so the search stays fast.
          

          
    
            
  • AIC (min): rewards goodness-of-fit but penalizes extra predictors. Lower is better.
    • 
            
  • Max predictors: controls the largest model size considered (e.g., 3 → models of size 1, 2, or 3).
    • 
            
  • Compare overlays: select the best subset model and a simpler model to see the trade-off visually.
    • 
          


          

            Tip: If you rank by AIC, a slightly worse RMSE model can still win if it uses fewer predictors.
          

        


        

          
Transforms & back-transform

          

            When a model uses log(y), the tool fits coefficients to ln(y) (fit space) and then converts predictions back to y using exp().
            Leaderboard comparisons and plots are shown in original y-units so models can be compared directly.
          

          
    
            
  • Domain checks: log models require positive inputs (x>0 and/or y>0).
    • 
            
  • Coefficient stats: reported in fit space (OLS/WLS exact). Derived parameters like A=exp(a) are informational.
    • 
          

        


        

          
CI vs PI

          

            
BandWhat it means

            
              
95% CI (mean)Uncertainty on the estimated mean response E[y|x]. Narrower than PI.

              
95% PIUncertainty for a new observation y at x. Includes both mean uncertainty and residual scatter.

            
          

          
Use PI for “what might the next datapoint be?” and CI for “what is the mean trend?”

          

          

            Transformed models: For ln(x) families, x is logged inside the fit (x→ln(x)), but CI/PI are still shown in original y-units.
            For ln(y) families, OLS/WLS compute CI/PI in ln(y) and then exponentiate the endpoints back to y (so bands become asymmetric).
            MUPE/ZMPE intervals are approximate (delta-method) on the y-scale.
          

        


        

          
MUPE vs ZMPE

          

            These minimizers fit in percent-error space using the signed percent error:
            eᵢ = (yᵢ − ŷᵢ) / yᵢ.
          

          

            
MinimizerObjective (concept)Notes

            
              

                MUPE
                Minimize Σ wᵢ · eᵢ² (least squares on percent errors)
                Rows with |y| near 0 are dropped (percent error undefined). Stats/CI/PI are approx/experimental.
              

              

                ZMPE
                Minimize Σ wᵢ · eᵢ² subject to mean_w(e)=0
                Implemented via a penalty term α·mean_w(e)² (larger α enforces closer to zero-mean % error).
              

            
          

          
Rule of thumb: MUPE minimizes overall percent scatter; ZMPE additionally targets no average percent bias.

        


        

          
Exports

          
    
            
  • Excel formula copies an = formula using your dataset’s column order (row 2 by default).
    • 
            
  • Coef TSV is designed for Excel paste (tab-separated columns).
    • 
            
  • Preds + intervals exports per-row predictions (and CI/PI where available).
    • 
            
  • Leaderboard TSV/CSV exports the ranked model rows for spreadsheet comparison.
    • 
          

        


        

          
Caveats

          
    
            
  • Approx labels: MUPE/ZMPE coefficient stats and interval bands are marked approx/experimental because the objective is nonlinear and constraint penalties can change inference behavior.
    • 
            
  • Overfitting: higher-order polynomials and many predictors can fit noise. Prefer simpler models when performance is similar.
    • 
            
  • Extrapolation: predictions far outside the x-range can be misleading even with high R².
